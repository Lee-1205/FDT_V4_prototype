# Research References

These files are evidence and design input, not executable authority. The repository's checked-in source, tests, pinned configuration, run manifest, and measured artifacts define what was actually implemented.

- Exact Memory beside fuzzy semantic anchors
- proposal recall and fallback behavior
- generated-prefix loop recovery and repetition control
- 8K/16K state retention
- the missing 2K/4K curriculum bridge
- performance profiling interpretation
- audit and GitHub ledger practices
